# 구현 계획 및 수용 기준

초기 버전 구현 기록입니다. 현재 후속 변경은 [Revision 2](REVISION-2.md)를 따릅니다.

사용자가 지정한 8개 기능을 독립적인 정적 Creation 앱으로 구현했다. 외부 서버, 로그인, 마이크, LLM은 필요하지 않다.

1. [완료] 공식 SDK 계약에 맞춘 리듬 계산·10초 탭 측정·유니코드 기기 저장. 4/4에서 4·8·12 클릭, 기본 1박 강조, 80 BPM 측정, 한국어 제목 저장 및 복원 검증.
2. [완료] Web Audio 예약 시계 및 UI. 입력·휠·우측 버튼, 두 음색, 강조, 무음 시 시각 박자와 예약 소리 취소 검증.
3. [완료] 단일 HTML 빌드·설치 QR 도구·사용 안내. 외부 런타임 의존성 없는 정적 호스팅 패키지와 공식 JSON QR 형식 검증.
4. [완료] 브라우저 사용·화면 검증·독립 리뷰. 240×282 모든 화면, 실제 10초 탭, 영속성, 비동기 오디오·저장 오류 처리. 자동 브라우저 11/11, 추가 실행 25/25, 단위·회귀 9/9, 최종 독립 게이트 PASS.

BOOMER-6 검토: SDK 이름은 공식 소스로 확인; 숫자와 제목은 경계에서 검증; 노드와 타이머는 정지 시 해제; 큰 프레임워크와 음원 다운로드는 배제; 저장은 비동기 순서를 보장; 하드웨어 실기 검증은 별도 명시.

## 확인 범위와 제한

실물 r1 접근 권한이 없어 스피커·OS 오디오 정책·QR 스캔 설치는 직접 확인하지 않았다. 공개 배포는 수행하지 않았으며 설치 패키지와 QR 도구를 제공한다.

Lighthouse 성능 측정은 저장 공간 부족과 Chrome 프로필 오류로 점수를 얻지 못했다. 성능 도구를 표준 패키지 관리자로 제거해 공간을 확보했고 기본 검증·빌드·의존성 감사는 다시 통과했다. [세부 기록](../qa/lighthouse-summary.md).
