# PULSE 사용 피드백 반영 · Revision 2

## 요구사항과 수용 기준

1. r1 휠 방향 반전: scrollUp -1, scrollDown +1. PC 휠도 같은 방향. +/-와 키보드 화살표는 표시 방향 유지.
2. 무음 화면 신호 강화: 4분음표마다 110ms 주황 펄스, 최대 불투명도0.62. 헤더·내비게이션은 덮지 않고 터치를 통과. 분할음마다 깜빡이지 않음.
3. 음색별 두 소리: 드럼 강조 킥150→45Hz / 일반1000Hz 클릭. 멜로디 강조880Hz / 일반660Hz. 분할음은 일반음과 동일하며 음계 진행 없음.
4. 음량 UI 제거: 기기 기본 음량 사용. 앱 출력은 mute0/unmute1, 이전 저장 volume은 제거해 재생이나 복원에 영향 없음.
5. 실시간 탭: 두 번째 탭부터 BPM 표시·즉시 반영, 최근 최대4간격 평균. 100ms 미만 중복 무시, 4초 초과 쉼 후 새 측정. 10초 종료와 카운트다운 없음. 잘못된 범위는 표시하고 현재 템포에 적용하지 않음.
6. 소리 탭의 중복 ‘무음 · 화면 박자’ 행 제거. 상단 무음 버튼과 강조 설정은 유지.

## 검토 경계

기존 저장 곡을 유지하며 읽기 실패 시 덮어쓰지 않는 정책을 유지. Chrome에서 SDK 이벤트·저장을 모의하고 실제 Web Audio를 사용한다. 실물 r1 확인은 수행하지 않았음을 명시한다. 사용자 선택대로 사이트 접근을 공개로 전환하지 않는다. 트레이더 파일은 수정하지 않는다.
