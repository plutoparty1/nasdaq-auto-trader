# Revision 3 · 빠른 피드백 반영

범위: 기존 메트로놈의 작은 제어 수정, 저장 형식·비공개 접근 유지.

수용 기준:
1. 분할 버튼 선택 시 기본 강조를 설정: 4분 첫 박, 8비트 [강/약]×4, 셋잇단 [강/약/약]×4. 1–4 강조 버튼으로 사용자 변경 가능, 저장 곡의 명시적 강조는 복원.
2. BPM type=number/inputmode=numeric로 숫자 자판 요청. 영문·기호·혼합 붙여넣기는 현재 숫자를 바꾸지 않고 무시. 빈 입력·20–300 범위 검증 유지.
3. 멜로디 강조880→1320Hz, 일반660Hz 유지.
4. 탭 초기/초기화의 ‘실시간 BPM 측정’ 문구 제거. 측정 후 단위는 BPM.

상태: 회귀 RED 확인·구현 완료 → 단위11/브라우저16/실제사용25 검증 완료 → 모든5검토 영역 PASS → 비공개 버전3 배포 succeeded, ZIP 갱신 완료.

런타임 가설: H1 현재 type 없는 text 입력이 영문자판 요청 원인이다(현재 DOM 확인). H2 inputmode는 OS 힌트이므로 type=number와 결합해 강화하되 물리 r1 자판은 브라우저에서 증명할 수 없다. H3 기존 파서는 저장 시에만 영문을 거부해서 입력칸 자체가 바뀐다(현재 change 이벤트 확인); 입력 이벤트 단계 차단 회귀로 검증한다.
