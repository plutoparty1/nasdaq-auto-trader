# PULSE · rabbit r1 설치

이 폴더에는 완성된 앱과 설치 QR 도구가 있습니다.

- **index.html**: 메트로놈 앱. PC에서 더블클릭해 미리 볼 수 있습니다.
- **install.html**: r1 설치용 QR 만들기. 이 파일도 PC에서 더블클릭하면 열립니다.

## r1에 설치

1. 이 폴더를 Netlify Drop 또는 GitHub Pages 같은 정적 호스팅에 올립니다.
2. 인터넷에서 열리는 앱의 HTTPS 주소를 확인합니다.
3. PC에서 install.html을 열고 해당 주소를 입력한 뒤 설치 QR을 만듭니다.
4. r1에서 **creations → add via QR code**를 선택해 QR을 스캔합니다.
5. 설치된 PULSE 카드를 엽니다.

QR에 임의의 예시 주소를 넣으면 앱이 설치되지 않습니다. 실제 배포 주소를 넣으세요.
공식 설치 안내: https://www.rabbit.tech/support/article/how-to-use-r1-creations

## 조작

- 휠 위/아래: 템포 1 BPM 증감. 숫자를 눌러 20–300 BPM 직접 입력.
- 우측 버튼 또는 재생 버튼: 재생 / 일시정지.
- 4분 / 8비트 / 셋잇단: 한 마디 4 / 8 / 12개 클릭. BPM은 4분음표 기준.
- 1–4 숫자: 강조 박자 켜기 / 끄기.
- 소리: 드럼 / 멜로디, 음량, 무음 모드.
- 탭 측정: 첫 탭부터 10초 동안 일정하게 탭. 4회 이상. BPM 확인 후 템포 적용.
- 내 곡: 제목 music1 입력 후 저장하면 80-music1 같은 이름으로 표시. 선택하면 설정 복원.
- 삭제: 삭제를 누르고 확인.
- PC: 화면의 +/- 또는 마우스 휠. ↑/↓ 템포. 입력 필드·버튼 밖에서 Space 재생.

곡은 r1 Creation 저장소에 UTF-8 Base64로 저장되어 한국어 제목도 유지됩니다.
PC에서는 브라우저에 저장됩니다. PC와 r1의 저장 데이터는 각각 별개입니다.

앱이 숨겨지면 재생과 탭 측정이 중단됩니다. 탭 화면을 벗어나거나 재생을 시작하면 진행 중인 탭 측정은 취소됩니다.

## 확인 범위

PC Chrome 실제 실행, 오디오 예약·무음, 기기 이벤트 및 저장 API 계약을 검증했습니다.
실물 r1의 스피커·OS 오디오 정책·QR 스캔 설치는 실기 확인이 필요합니다.
이 패키지는 아직 공개 URL로 배포하지 않았습니다.
