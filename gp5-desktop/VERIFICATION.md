### 1.1.0 Mac 패키징 후속 작업

사용자의 Mac 빌드 요청으로 Intel·Apple Silicon용 ZIP을 Windows에서 생성했습니다. 두 ZIP은 `GP5 PDF.app`과 한글 수정·악기 선택 기능을 담습니다. macOS 최소 버전은 번들 plist 기준 13.0입니다.

| 아키텍처 | 파일 | 크기 / SHA-256 |
| --- | --- | --- |
| Intel x64 | `release/1.1.0/GP5-PDF-macOS-x64-unsigned-unverified.zip` | 155,044,032 bytes / `19f5ae36262f4ba30e65119beb8d0cfb5cbcbf66a424f56679c9f7ba1c6ae6d8` |
| Apple Silicon arm64 | `release/1.1.0/GP5-PDF-macOS-arm64-unsigned-unverified.zip` | 152,375,146 bytes / `f19049a1a850fd27693c0009bbaab7f6969fc415040c610538507890b949a832` |

공식 Electron 체크섬과 원본 실행 엔진이 일치합니다. ZIP마다 Unix 항목 583개·심볼릭 링크 14개·실행 파일 13개를 보존했고, 변경 대상 이외 모든 항목의 실제 바이트가 원본과 같습니다. ZIP CRC, CPU 종류, 버전 1.1.0, 앱 ASAR 일치와 Windows 전용 네이티브 모듈 부재를 확인했습니다. 공통 ASAR 해시는 `13c458ac397f79d4e529d7023b7ca3fcce9699ad218762d016b46b98f3a90071`입니다.

패키징 CLI의 정상 생성, 잘못된 인수 거부, 기존 출력 덮어쓰기 거부를 실행 검증했습니다. Python 타입 검사·포맷·스킬 규칙 검사는 통과했습니다. Ruff 전체 규칙 검사의 기존 경고 6개(CPY001 저작권 머리말, COM812 쉼표)는 버전 변경 전후 동일하며 새 경고는 없습니다. 이번 소스 변경은 패키징 버전 1.0.0 → 1.1.0 한 줄입니다. 근거: `qa/macos-1.1.0-*`, `qa/macos-artifacts-1.1.0.json`.

현재 호스트가 Windows이므로 Mac의 실행·실제 PDF 출력·코드 서명·공증·Gatekeeper는 검증하지 못했습니다. 파일명에 `unsigned-unverified`를 유지했습니다. 이 결과는 Mac에서 확인된 정식 배포본을 뜻하지 않습니다.

### 1.0.0 오류 가설과 확인

1. 트랙이 섞이거나 빠질 수 있음: 실제 생성한 PDF 3개의 텍스트와 페이지 이미지를 비교해 악기별 분리를 확인했습니다.
2. 재실행·동시 저장·취소가 파일을 손상할 수 있음: 독점 파일 생성, 충돌 번호, 원본/기존 파일 해시, 부분 파일 정리를 검증했습니다.
3. 인쇄가 멈추면 취소도 멈출 수 있음: 수정 전 중단·시간 초과·크래시·창 닫힘 테스트 4개가 실패했습니다. 전체 렌더링·인쇄 작업에 중단 처리를 적용한 뒤 모두 통과했습니다.
4. 창이 가려지면 검증용 프레임 대기가 멈출 수 있음: 최종 EXE가 PDF를 모두 생성한 뒤 스크린샷 대기만 시간 초과됐습니다. 검증 도구에서 창을 앞으로 가져오고 백그라운드 대기를 해제해 최종 캡처와 검증을 완료했습니다. 제품 코드에는 디버그 진입점을 추가하지 않았습니다.

### 1.0.0 당시 검증의 한계

- 실제 Windows 파일 선택창의 마우스 클릭과 탐색기 창 열기는 제어 도구 연결 문제로 직접 검증하지 못했습니다. 선택창 반환값과 폴더 열기 경계만 대체했고, 앱 화면·IPC·악보 엔진·PDF 저장은 실제 구현을 실행했습니다.
- Mac이 없어 실행·PDF 생성·코드 서명·Gatekeeper 검증은 하지 못했습니다. Mac ZIP은 개발용 스테이징 결과물이며 일반 사용자 배포 완료를 뜻하지 않습니다.
- 당시 한글 제목 레이아웃 검증은 GP5에서 읽은 모델을 한글 메타데이터로 바꿔 GP7로 저장한 렌더러 검증용 악보를 사용했습니다. CP949 트랙명 깨짐은 1.0.0의 제한이었으며 위 1.1.0에서 실제 GP5 바이트 자료로 수정·검증했습니다.
- Windows 실행 파일과 Mac 스테이징 앱에는 배포자 코드 서명·공증을 수행하지 않았습니다.
