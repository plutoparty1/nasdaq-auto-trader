# 정식 운영본 사용법
실행파일: C:\Users\u\nasdaq-auto-trader\deploy-operating\NasdaqAutoTrader\NasdaqAutoTrader.exe
빌드: formal-production-20261013-r1. 첫 실행은 paused/waiting, production_approval_required, submission_enabled=false이다. 기존 실계좌 승인을 복사하지 않는다. Safe.exe 두 배포본과 기존 dist EXE는 별도 그대로 보존한다.

## GUI 조작
1. 기존 트레이더가 열려 있으면 먼저 그 창의 정상 중지/종료를 사용한다. 이 개발 작업은 기존 프로그램을 종료하거나 주문 취소/청산하지 않았다. 새 GUI 사전점검은 다른 NasdaqAutoTrader 프로세스가 있으면 차단한다. PID43856을 현존 프로세스로 가정하지 않는다. 실전 예약 작업은 켜지 않았다.
2. 새 EXE를 연다. 자동으로 운영하거나 승인하지 않는다. `모의 실행`은 실제 시세를 읽는 dry_run이다. 실제 주문 전송기가 연결되지 않는다. 합성 신호는 `--replay` 임시 시험에만 사용한다.
3. `실전 사전점검`을 누른다. KIS 계좌와 NASD/NYSE/AMEX 보유·미체결을 읽기 전용으로 확인한다. 최종 전략, 실행본 SHA256, 계좌 마스킹, 수량, 최종 한도와 출처, 비용 가정, 차단 사유가 로그에 표시된다. 차단 사유가 있으면 승인으로 무시할 수 없다.
4. `조건 확인 / 명시 승인`을 눌러 같은 조건을 검토한다. 현재 수수료는 미확인이다. 사용자가 실제 수수료표를 확인한 경우에만 체크하고 `수수료 확인 상태 저장 · 사전점검 다시 필요`를 누른다. 이것은 승인이 아니다. 설정이 바뀌었으므로 다시 사전점검한다.
5. 다시 조건 확인 창을 열고 수수료 확인 체크 및 표시된 정확한 문구를 직접 입력한다:
   I UNDERSTAND THIS WILL PLACE REAL ORDERS DURING ONE NASDAQ SESSION
   `표시된 조건을 명시 승인 (운영 시작은 별도)`를 누른다. 기존 authorize_live_session 검증을 통과해야 새 실행본/계좌/전략/최종설정에 묶인 당일 승인 기록이 생성된다. 승인만으로 운영을 시작하지 않는다.
6. `승인 범위 자동운영 시작`을 별도로 누른다. 승인/조건/정규장/다른 프로그램/계좌 잠금을 다시 확인한다. 기존 전략의 정상 신호·수량·위험·현금·비중 검사를 모두 통과한 주문만 KIS 경로로 전달된다. 파일 또는 조건을 변경하면 승인 불일치로 차단한다.
7. `신규 진입 중지`는 BUY를 막고, 기존 유효 승인 안의 보유분 보호 매도·대사는 계속한다. 승인 만료/불일치 시 주문 권한은 유지되지 않는다.
8. `전체 종료`는 종료 확인을 거쳐 모든 판단·보호 매도·주문 대사를 중단하고 창을 닫는다. 미체결 취소나 보유분 청산은 자동 수행하지 않는다. 이미 진행 중인 주기는 정상 반환을 기다린다. 재시작 시 자동으로 실전 운영을 재개하지 않는다. 운영본이 기록한 매수 주문번호·거래일·체결 내역과 보유분이 일치할 때만 자체 보유분으로 인정하고, 원래 일일 손실 기준액을 복원한다. 주문번호 없는 불명확 응답, 출처가 불명확한 보유분, 기록되지 않은 미체결 매도는 별도 대사·검토 전 차단된다. 이 GUI는 그 보유분을 임의로 인수하지 않는다.

## 현재 미승인 초안
고정1주, 종목별최대1주, 추가매수금지. 기본 종목5%/전체30%, 거래위험1%, 초기고정손절3%, 일일손실2%, 기본주문상한$100. 기존 전략/AI 제한의 주문상한$35가 더 엄격하므로 $35가 적용된다. 종목한도는 $62.91×5%=$3.1455로 $20.61 1주는 승인과 별개로 차단된다. 강제최소매수·위험우회·동일완성봉 반복진입은 허용되지 않는다. 왕복비용0.5%는 계획 가정이며 실제 수수료 확정값이 아니다.

GUI에는 투자한도 편집기가 없다. 한도 변경은 프로그램을 정상 종료한 뒤 EXE의 `draft-limits --help`에 표시된 옵션을 사용하여 사용자가 별도로 결정한다. 백분율5는5%이다. 이 명령은 초안만 수정하고 수수료 확인을 초기화하며 새 승인이나 운영 시작을 발급하지 않는다. 고정1주는 바꾸지 않는다. 변경 후 다시 사전점검/조건검토/명시승인이 필요하다. 이 개발에서 투자한도를 확대하지 않았다.

## 정확한 CLI
EXE `--help`, `authorize-live-session --help`, `draft-limits --help`가 실제 구현된 도움말이다. CLI 승인에는 `--confirm`과 사전점검의 `--review-digest`가 필요하다. 승인 CLI도 새 사전점검과 동일한 기존 검증을 거치며 자동운영 시작은 GUI에서 별도로 한다. 계좌/토큰/EXE를 직접 편집하여 잠금을 해제하는 방식은 없다.

## 시험 구분
최종 EXE `--replay <JSON경로>`는 임시 시험계좌00000000/시험승인/가짜 KIS 전송기를 사용한다. 소켓 연결을 차단한다. 정상전략에는 합성 봉을 입력하지만 실제 전략 decide를 실행하고 자동선정·위험검사·승인·KIS 주문 직렬화·대사·저장을 연결한다. 실제계좌 승인파일을 만들지 않는다. 실주문 수락/체결/실제수수료/실전 부분체결은 검증하지 않았다.
