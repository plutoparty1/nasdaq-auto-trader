최종 결론

로컬 증거 기반 적응형 퀀트 연구·운영 체계

시간이 지날수록 개선해야 하는 것은 누적 수익의 단조 증가가 아니라 전략 선택 오류, 비용 추정 오차, 주문 중복, 자료 누수, 이상 감지와 복구 시간이다.

수익의 단조 증가는 보장할 수 없다. 새 자료는 챔피언을 곧바로 교체하는 명령이 아니라 도전자의 증거를 누적하는 입력이다. 이는 백테스트 과최적화 확률과 축소 샤프비율 연구가 지적하는 선택 편향을 줄이는 방향이다.

현재 상태

현재 구현은 연구·검증·주문 보호의 뼈대지만 운영 폐루프는 아니다. 이미 구현된 과거 데이터 기반 종목 자동 선택은 제한된 명령줄 실전 경로에서 영속 주문 고유키·중복 거절·재시작 복구를 적용한다. 아래 우회 문제는 그 경로가 아니라 별도의 인공지능 퀀트 연구실 실전 주기에 한정된다.

단절

후보 생성

운영 제공자는 연구 문맥을 버리고 후보 파일만 읽는다.

과대표현

검증 지표

현재 정화 교차검증·조합 정화 교차검증·백테스트 과최적화 확률은 실제 학술 절차가 아니라 다섯 구간 수익과 수익률 부호 변화로 만든 대리점수다.

우회

별도 연구실 실전 주기

인공지능 퀀트 연구실 실전 주기가 자동 종목 선택 경로의 더 강한 영속 주문 허가문과 재시작 뒤 주문 결과 불명 상태 처리를 우회한다. 최종 구조는 기존 보호를 공통 관문으로 승격한다.

미연결

체결 피드백

한국투자증권 주문 제출은 가능하지만 부분체결·취소·실현손익이 야간 개선 작업으로 돌아오지 않는다.

직접 재현: 선형 상승 자산곡선 하나가 현재 구현에서 정화 교차검증 1.0, 조합 정화 교차검증 1.0, 백테스트 과최적화 확률 0.0, 승격 가능 판정을 받았다.

최종 구조

대용량 변경 불가 기록은 파케이 파일, 운영 상태는 에스큐엘라이트, 분석은 덕디비, 관계의 기준은 관계형 질의 외래키에 둔다.

  1. 1. 증거 수집시장자료, 기업행사, 과거 종목군, 한국투자증권 주문과 체결
  2. 2. 제한 탐색형식이 정해진 전략 문법과 단일 작업 순차 탐색
  3. 3. 실제 검증순차 표본외, 정화·금지기간, 조합 정화 교차검증, 과최적화 확률, 축소 샤프비율, 우월 예측능력 검사
  4. 4. 단계 승격종이거래, 그림자거래, 사람 승인, 소액 챔피언
  5. 5. 단일 주문 관문영속 허가문, 중복방지, 독립 위험 통제
  6. 6. 한국투자증권 대사응답 불명, 부분체결, 정정·취소, 웹 조회 종결 확인
  7. 7. 체결 귀속수수료, 체결 미끄러짐, 비용 모델과 전략별 손익
  8. 8. 제한 적응가중치 갱신, 변화 경보, 동결과 재검증

외부 언어 모델과 사용자 위임 인증

사용자 위임 인증으로 오픈에이아이 응용프로그램 인터페이스를 추가 과금 없이 사용하는 공식 방법은 확인되지 않았다. 이 접속 수단은 별도 비밀키를 쓰는 별도 과금 제품이며 챗지피티 구독과 청구 체계가 분리된다. 공식 빠른 시작과 별도 과금 안내에서 확인할 수 있다.

허용

연결되지 않은 연구 보조

전략 문법 초안, 실패 실험 요약, 논문 분류. 모든 출력은 검증되지 않은 입력으로 취급해 별도로 검증한다.

금지

거래 핵심 경로

실시간 신호, 직접 주문, 위험 우회, 챔피언 승격, 비밀키와 원시 계좌자료 전송.

코덱스의 챗지피티 요금제에 포함된 사용량은 개발·검토에만 사용한다. 자동 충전을 끄면 포함량 초과 시 추가 지출을 막을 수 있지만 이를 프로그램에서 쓰는 무료 언어 모델 접속 수단으로 간주하지 않는다. 코덱스 포함 사용량 안내에도 사용량 제한과 별도 크레딧 체계가 명시되어 있다.

연구는 거래 프로그램이 정지되어 있고, 장 마감 후 한국투자증권 대사와 감사 기록이 완료됐으며 미확정 주문이 없을 때만 시작한다.

구현 순서

  1. 주문과 상태 무결성

    단일 영속 주문 관문, 한국투자증권 상태기계, 웹 조회 대사, 실전 자료 검증, 원자적 레지스트리.

  2. 자료와 실험 계보

    변경 불가 스냅숏, 사건·수집시각 분리, 모든 탐색 시도, 비용 모델, 야간 작업 고유키.

  3. 검증 엔진 교체

    실제 순차 표본외, 정화·금지기간, 조합 정화 교차검증과 과최적화 확률, 축소 샤프비율, 우월 예측능력 검사, 스트레스 검사.

  4. 제한 탐색과 단계 승격

    형식이 정해진 전략 문법, 순차 옵튜나 탐색, 종이·그림자·사람 승인·소액 챔피언.

  5. 제한적 온라인 적응

    체결 비용 보정, 비용 포함 기준선, 지수 가중 또는 고정 공유 전문가 결합, 적응 창 변화 경보.

  6. 선택적 의미 검색과 외부 언어 모델

    에스큐엘라이트 전문검색부터 시작하고 벡터·그래프·외부 언어 모델이 꺼져도 핵심 경로가 동작하도록 유지.
