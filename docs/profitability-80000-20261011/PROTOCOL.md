# 80,000원 수익성 탐색 비교: 계산 전 고정

2026-10-11. 새 후보 성과를 계산하기 전에 고정한 평가 규약이다. 사용자 요청은 실행 승인으로 취급한다. 목표는 후보 채택 여부이며 월 +10%를 달성하도록 최적화하지 않는다.

- 원래 A/B/C 1% 자료와 파일을 보존한다. 과거 실전 5% 예외의 재현이 아니다.
- 새 후보는 C, 기존 fixed_8, fixed_10, entry_atr14x3_1day × 거래당 위험 1/2/4%의 12개다. 가격/수익 결과에 따라 후보·구간·숫자를 바꾸지 않는다.
- C는 3% 고정손절, 5% 익절, +2% 활성/최고 관측가격 대비 1% 추적, 현재 일봉 ATR14×3 손절/×5 익절을 유지한다. C는 교정된 비교 기준선이다.
- fixed_8은 8/16/8/4%, fixed_10은 10/20/10/5%. ATR은 완성 일봉14×3을 진입 시 동결, 0.5~10% 거리 밖 거부, 16% 익절/+8% 활성/4% 추적. 기존 ExperimentalExitStrategy를 재사용한다. 일반 기술매도 점수4는 모든 후보에 남긴다. fixed/진입 ATR 묶음에는 동적 ATR 익절이 없다.
- C의 신규 수량 계산은 실제 최초 손절선인 max(가격×0.97, 가격−진입ATR×3)까지의 거리와 예상 왕복비용이다. 원래 C의 max(3%, ATR거리) 보수적 위험 대리값과 구분한다. 손절 수치와 청산 코드를 바꾸지 않으며 옛 C 결과를 덮어쓰지 않는다.
- 공통: 초기80,000원/시작시점 ECB FX, 정수1주, 종목당 최대1주, 추가매수없음, 주문$35, 종목당/전체50%, 현금여유5%, 일일 계좌손실2% 신규진입중단. 새 비교에는 기존 조기청산 실험의 동시 계획손실6% 합계 상한을 공통 적용한다. 옛 A/B/C에는 이 합계 상한이 없었다.
- 수량은 위험으로 가능한 정수수량과 자금/주문가능금액/투자한도/고정1주 중 작은 값이다. 1주를 감당하지 못하면 0주이며 위험예산을 높여도 1주 상한을 풀지 않는다.
- 비용은 기존 base(편도0.25%, 최소$0, 스프레드10bp, 슬리피지10bp)와 stress(0.30%, 최소$0.10, 각각30bp). 실제 계좌 청구액 확인값이 아니다. 최소$0은 비례수수료 면제가 아니다. 정확한 판매부과금·환전비용·운영비는 미확인이다.
- 새 체결은 양수 거래량인 다음 봉 시가에서 불리한 스프레드/슬리피지를 더해도 매수 지정가 이내일 때만 허용한다. 장중 단순 저가 접촉은 체결로 보지 않는다. 매도는 다음 시가에서 불리한 비용을 반영한다. 호가 대기열은 알 수 없어 보수적 체결 가정이지 실제 체결 보장이 아니다.
- 일봉 후보 보호는 기존 엔진의 관측 종가에서 판단하고 다음 봉에 청산한다. 최고 관측 종가만 갱신한다. 당일 고가를 먼저 알고 추적선을 올리지 않는다. 일중 고저 순서와 손절선 체결을 복원하지 않으며 8/10%를 실현손실 상한으로 해석하지 않는다. 같은 봉 내 손절/익절은 기존 판정 순서를 유지하고 익절에 유리한 순서를 가정하지 않는다.
- 자료: 기존 공개 CMCSA/KDP/HIVE 2026-01-06 이후 자료의 기존 final 구간, KDP/HIVE 519봉의 기존 train/validation/final 구간. 원래 64봉 준비/2025-08-29·2026-02-27 경계를 유지한다. 모두 이미 본 개발·탐색 자료다. final은 파일 구간명일 뿐 독립 검증이 아니다. 새 독립 시세는 이 실험에 확보하지 않는다.
- 기존 4거래일 5분 자료는 이전 완성 일봉 지표와 장중 보호의 제한을 설명하는 보조 자료다. 일봉 지표를 5분봉 지표로 바꾸지 않고 4일 성과를 월/연으로 확대하지 않는다.
- 비교 기준: USD 현금(이자0, 같은 FX), 동일 종목군의 사전 균등예산·정수매수 후 보유(종목별1주와 공통 투자한도, 불가능한 종목 예산 재배분없음), 동일군 분수형 균등 가격지수는 실행불가 참고치로 별도 표시. 배당 미반영 가격수익이며 보유기간 배당 누락은 보고한다.
- 월 지표는 미실현손익 포함 계좌평가액, 완전 달력월과 부분월을 구분한다. 구간은 80,000원에서 각각 재시작하므로 합산한 독립 성과로 표현하지 않는다.
- 채택 근거: 비용 후 양의 성과, 현금/실행가능 단순보유 대비 일관성, 비용 스트레스 생존, 여러 완전 월과 충분한 거래의 반복성. 거래0 또는 극소수/한 구간만 우위/비용에 소멸하면 채택하지 않는다. 통계적 입증이나 미래확률을 주장하지 않는다.
