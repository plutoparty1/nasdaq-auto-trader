계획 손실 = `q × (신호가격 − 초기손절가격) + fee(q×신호가격) + fee(q×손절가격) + q×(신호가격+손절가격)×불리한 체결비율`. 초기 손절은 신호가격의 92%이며, 실제 모의 체결 시 체결가를 기준으로 한도를 다시 검사한다. 최소수수료는 수량별 주문 총액으로 계산한다. 실제 관측 손실은 계획 2%로 자르지 않는다. 거래별 계획 위험·초과액·수수료·체결 영향·손절 이후 가격 변동을 기록하며, 일봉만으로 지연의 독립적인 손익 기여를 확정할 수 없으면 미확정으로 표시한다.

## 모의 체결과 비용

매수 판단은 종가를 수신한 뒤 수행한다. 다음 거래일 시가에 불리한 체결비용을 더한 값이 지정가(신호 종가) 이내이고 거래량이 양수여야 모의 체결한다. 저가가 지정가에 닿았다는 이유로 체결하지 않는다. 다음 기회에 조건을 못 맞추면 미체결로 거절하며, 조회를 놓친 주문은 유효기간 경과로 기록한다. 주문 전체 체결 또는 거절 모형이며 부분 체결·대기열·호가 잔량을 재현하지 않는다. 매도도 다음 시가에 불리한 비용을 적용한다.

일봉 공급 특성상 다음 시가의 모의 체결은 다음 완성 일봉을 수신한 뒤 **사후 계산**한다. 그 주문의 실제 판단 시각이 해당 시가보다 앞섰는지 확인한다. 시장 발생 시각, 응답 수신 시각, 실제 판단 시각, 모형 체결 시가 시각, 체결 계산 시각을 구분한다. 실시간 체결 기록이나 정밀한 실제 체결 재현이라고 부르지 않는다. 조회 누락을 나중에 보충한 봉은 지표에만 사용하며 과거 진입·계좌 수익 시점을 새로 만들지 않는다.

| 비용 조건 | 편도 매수/매도 수수료 | 편도 최소 | 전체 스프레드 | 편도 슬리피지 | 상태 |
|---|---:|---:|---:|---:|---|
| base | 0.25% / 0.25% | $0 | 10bp, 편도 절반 적용 | 10bp | 기존 미확인 추정값 |
| high_impact | 0.25% / 0.25% | $0 | 30bp, 편도 절반 적용 | 30bp | 수수료 동일, 체결비용만 확대 |

따라서 가격 영향은 편도 15bp / 45bp이다. 가격에 포함한 영향액을 다시 차감하지 않는다. USD 거래마다 환전비용을 반복 부과하지 않는다. 계좌 실제 수수료·최소수수료·매도 부과금·환전비·운영비는 미확인, 배당은 미반영이다. 과거 편도 최소 $0.10 결과는 별도의 미확인 가상 시나리오로 기존 보고서에 남아 있고 이번 장부에는 사용하지 않는다. 두 장부의 거래는 독립 표본으로 합산하지 않는다.

## Windows PowerShell 수동 실행

아래 명령은 저장소 루트에서 실행한다. 한 번 실행하고 종료하며 예약이나 상주 기능이 없다. `dry_run`은 기존 코드에서 주문 제출만 막는 경로여서 이 가상 계좌로 사용하지 않는다. 실제 브로커 잔고·설정을 읽거나 대체하지 않는다. 기존 비교 CLI는 네트워크와 하위 프로세스 접근을 차단한다. 공개 수집기만 인증 없이 고정 공개 주소에 GET 요청한다.

```powershell
Set-Location 'C:\Users\u\nasdaq-auto-trader'
$py = 'C:\Python314\python.exe'
$paper = Join-Path $env:LOCALAPPDATA 'NasdaqAutoTrader\research\p1-paper-v1'

# 최초 한 번만. 준비 과정에서 이미 초기화했으면 다시 실행하지 않는다.
& $py -B scripts/run_entry_policy_comparison.py --p1-paper init --paper-dir $paper

# 상태 조회: 주문 또는 자료 수집을 하지 않는다.
& $py -B scripts/run_entry_policy_comparison.py --p1-paper status --paper-dir $paper
```

정규장 종료 후 일봉이 완성된 뒤, **다음 정규장 시작 전**에 필요할 때 수동으로 다음을 실행한다. 실제 수신·판단 시간을 기록하므로 늦게 확보한 자료를 과거에 알았던 자료로 취급하지 않는다. 최초 고정 뒤 완성 일봉이 없으면 독립 평가가 시작되지 않는다.

```powershell
$receiptDir = Join-Path $env:LOCALAPPDATA ('NasdaqAutoTrader\research\p1-receipts\' + (Get-Date -Format 'yyyyMMdd-HHmmss-fff'))
& $py -B scripts/collect_public_entry_data.py --p1-receipt --collect --output $receiptDir --calendar experiments/p1_paper_v1/sessions.csv
# 수집 일부 실패 시에도 receipt.json이 있으면 장애를 기록하고 유효 종목의 보호 판단을 처리한다.
$receipt = Join-Path $receiptDir 'receipt.json'
if (Test-Path -LiteralPath $receipt) {
    & $py -B scripts/run_entry_policy_comparison.py --p1-paper resume --paper-dir $paper --receipt $receipt
}
& $py -B scripts/run_entry_policy_comparison.py --p1-paper status --paper-dir $paper
```

`resume`은 저장된 가상 현금·보유·평균 체결가·모의 체결·미체결·비용·실현/미실현손익·초기 손절·최고가·봉/신호 ID를 복원하고 새 입력 한 묶음만 처리한다. 같은 입력 재실행은 중복 체결을 만들지 않는다. 누락·오래된 자료는 신규 진입을 막고 장애로 기록한다. 유효 시세가 있는 보유분의 보호 판단은 유지한다. 변경된 과거 봉·환율, 설정·소스 해시 불일치는 별도 검토 대상이다.

체크포인트는 `%LOCALAPPDATA%\NasdaqAutoTrader\research\p1-paper-v1`에 버전별 불변 파일과 `CURRENT` 포인터로 저장한다. 손상 시 자동 초기화·과거 상태로 자동 되돌림을 하지 않는다. `init`은 비어 있지 않은 경로를 거절한다. 계좌 파일을 Git에 추가하지 않는다. 오류가 출력되면 상태 조회로 확인하며 `input_rejected=true`는 입력 적용 실패이다.

## 검증 범위

실제 Windows PowerShell 진입점과 오프라인 회귀 테스트의 결과는 같은 디렉터리 `p1-paper-verification.json`에 기록한다. 소스 해시 변동, 설정 변동, 중복 입력, 재시작 복원, 체결 시각, 자료 장애, 비용/위험 한도, 보호 매도 유지, 종료일 고정, 실주문 경로 차단을 확인한다. 전체 과거 비교·전체 테스트는 재실행하지 않는다.

**아직 검증하지 않은 것:** 새로운 실제 자료의 60일 성과, 실제 계좌 수수료·최소수수료, 실제 호가 대기열/부분 체결/유동성, 장중 보호 효과. 공개 자료 실제 수집도 이번 준비에서는 실행하지 않는다. 초기 계좌는 빈 상태이고 독립 성과는 아직 없다.
