## 고정한 조건과 계산

- **P0**: 기존 `fixed_8_risk2`, 기존 C 진입·고정 1주. **P1**: 같은 진입·동적 정수 수량. **P2**: 같은 동적 수량에 완성 일봉의 종가>SMA50, 종가>직전 20일 고가 최대, 거래량>직전 20일 평균을 모두 요구. 고가·거래량 기준은 당일 제외, 기존 매수 점수식을 대체합니다.
- 공통: 거래 위험 2%, 종목/총 투자 50%, 주문 $35, 현금 여유 5%, 보유+예약 계획손실 6%, 기존 일일 손실 신규매수 중단 2%. 추가매수·강제매수 금지, 동시 매도 신호 차단·중복 방지 유지. P1/P2의 수량이 0이면 건너뜁니다.
- 공통 청산 우선순위: **8% 초기 손절 → 16% 고정 익절 → +8% 이후 최고 관측가 대비 4% 추적 청산 → 일반 기술적 매도(점수 4)**. 별도 ATR 익절·시간 청산 없음. 일반 매도도 그대로 유지했습니다. 8%를 최적 손절로 해석하지 않습니다.
- 수량별 계획손실: `q*(P-S) + fee(q*P) + fee(q*S) + q*(P+S)*a`, `S=0.92*P`, `fee(n)=max(n*수수료율, 최소수수료)`. 실제 초기 손절 거리를 사용하고 기존 비용 포함 위험 대리값을 다시 더하지 않습니다. 최소수수료는 주문별 계산하며 1주 비용에 q를 곱하지 않습니다. 체결 시 현금·모든 비중/위험 한도를 다시 검사합니다.
- 이번 승인된 동적 주문에서 **다음 1주를 더하면 거래 위험 2%를 넘었습니다**. 50%·$35·6% 한도를 풀지 않았고, 종가 평가 시점의 최대 투자 비중은 24.61%였습니다. 준비기간 진단도 담긴 `sizing.csv` 전체 행 수를 성과 표본 수로 사용하지 않습니다.

## 데이터와 체결 한계

CMCSA·HIVE·KDP 모두 동일하게 평가했습니다. 종목당 기존 일봉 183개에서 준비기간 64개를 제외한 119개 평가 시점이며, 완전월은 5~8월 4개입니다. 준비기간은 수익 집계에서 제외했습니다. 이전에 사용한 사후 선정 종목군·기간이므로 파일의 `final` 분할명도 독립 최종 검증을 의미하지 않습니다.

완성 일봉 신호 이후 다음 거래 가능한 시점의 시가+불리한 가격 영향이 지정가를 만족하고 거래량이 있는 경우에만 모의 체결합니다. 같은 날 종가 선행 체결, 봉의 고저가 접촉만으로 체결하지 않습니다. 일봉의 장중 고저 순서는 모르며 보호 감시는 종가 기준입니다. 체결 기록의 시각은 해당 일봉의 종가 라벨이고 실제 시가 체결 시각이 아닙니다. 실호가 대기열·장중 보호 성능은 검증하지 못했습니다. 5분봉이나 새 데이터는 사용하지 않았습니다.

## 네 가지 판단

1. **자금 활용과 순손익:** P0→P1 평균 투자는 A 1.91→6.56%, B 1.99→5.74%; 순손익은 A $0.2457→$2.3057, B −$0.0665→$1.5681. P0/P1의 체결 시점·가격·사유와 거래별 주당 순손익은 동일합니다. 주당 평균 순익 A $0.039897, B $0.017635도 동일합니다. 거래 선택 개선 없이, 가격·평가액에 따른 서로 다른 수량 가중치가 손익 금액을 바꿨습니다.
2. **손실 위험:** 낙폭은 A −2.68→−7.47%, B −3.42→−7.44%로 커졌습니다. P1 기본 비용의 최대 완결 손실 $1.1984는 신호 시점 평가액의 2.1252%였습니다. P2도 최대 2.5714%/2.6836% 손실이 났습니다. 계획 2%는 지연 청산·갭 이후 실현 손실을 보장하는 상한이 아닙니다.
3. **새 진입:** P2는 양쪽 비용 모두 P1보다 낮고 완결 2건뿐입니다. 동시 매도 차단 등 공통 정책을 끄지 않았으며, 새 진입의 우위를 뒷받침하지 못합니다.
4. **후속 후보:** P1만 수량 정책 가설의 **잠정 독립 모의 검증 후보**입니다. 양쪽 비용에서 현금·기존 실행 가능 보유보다 누적 수익이 높지만, 낙폭 증가와 12/10건의 작은 동일 시장 표본 때문에 수익 전략 채택·위험 조정 우위·월 +10%를 주장할 수 없습니다. P0/P2는 넘기지 않습니다. 독립 자료 수집·평가나 실거래 연결은 이번에 하지 않았습니다.
