# 8만원 계좌의 1주 실행가능성: 사전 고정 첫 평가일

이 표는 **2026-04-09 20:00 UTC**, 주 비교 첫 평가의 기본 비용 36행(12개 프로필×3종목)을 그대로 사용한 조건 진단이다. 성과를 보고 유리한 날짜를 고르지 않았다. [원문 constraints.csv](main/constraints.csv), [전 정밀도 feasibility.csv](feasibility.csv), [고정 프로필](../../experiments/profitability_80000/profile.json). 코드·원본 산출물·실거래 한도는 변경하지 않았다.

초기 현금은 80,000원 / **$54.072814354631596**, USDKRW **1479.486521181001**(ECB 교차환율, 이용 가능 시각 4/9 16:00 UTC)이다. 계획 위험예산 1%/2%/4%는 각각 $0.540728/$1.081456/$2.162913, 약 800/1,600/3,200원이다. 이는 손절폭이나 투자 비중과 다른 값이다.

**이 시점에는 모든 프로필이 실제 HOLD다.** CMCSA·KDP 매수 점수 0, HIVE 4로 기준 5에 미달했다. CMCSA·KDP는 매도 점수도 6이다. 아래 재무 한도를 충족하는 것은 매수 신호나 다음 봉 체결을 보장하지 않는다. 총 위험 6% 한도도 보유·대기 주문과 함께 검사되며, 아래 최소자금은 보유·대기 주문 없는 전액 현금을 전제로 한다.

## 작성과 검증 범위

- 신규 파일은 feasibility.md와 feasibility.csv뿐이다. 원 시세·프로필·코드·주문 경로를 바꾸거나 후보를 재평가하지 않았다.
- 첫 평가 기본 비용36행을 원문과 연결해 가격·위험예산·초기 손절·비용·필요자금 수식을 대사했다. ATR은 기존 valid_atr 함수에 해당 시점까지의 완성 일봉만 넣어 확인했다.
- 최소 초기자금과 전체 바스켓 현금지출은 원 산출물과 절대오차 1e-10 이내로 일치했다. 모든36행 실제 신호는 HOLD이고 제출 예정 수량0이다.
- 이 표는 시점별 실행가능성을 보여준다. 이후 전체 구간의 성과·차단 건수·매도 원인은 본 비교 결과를 따른다.
