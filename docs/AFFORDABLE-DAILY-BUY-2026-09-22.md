# 잔액 기반 하루 첫 1주 정책

매수 후보를 유동성 상위 30개로 먼저 제한하던 경로를 수정했다. 계좌를 고려하는 자동 운용은 승인된 전체 종목 목록을 검사하고, 잔액·주문 가능 금액·투자 및 위험 한도에 맞는 후보를 대상으로 기존 학습 점수를 비교한다. 개별 종목의 시세나 호가 조회 실패는 해당 종목만 제외한다. 매수 가능 여부와 지정가에는 확인된 매도 1호가를 사용한다.

`daily_minimum_buy_enabled=true`는 미국 거래일 기준 하루 최소 1주를 목표로 하는 별도 정책이다. 수량은 1주이며, 일반 진입 점수 기준을 충족하지 않더라도 실제 매수 가능한 후보 중 최고 점수 종목을 선택한다. 사용자가 승인한 첫 1주 위험 한도는 계좌 자산의 5%다. 첫 1주 체결 확인 이후에는 기존 1% 위험 설정과 일반 학습 전략 제한으로 돌아간다. 기본 위험 설정을 영구적으로 변경하지 않는다.

현금, 현금 여유분, 종목/총투자 50% 한도, 최대 주문 금액, 손절, 일일 손실 차단, 장 운영 시간, 매매 권한, 미체결 주문/접수 내역 검사는 유지한다. 따라서 가능한 후보가 없거나 시장/계좌 조건이 허용하지 않으면 주문하지 않으며, 매일 실제 체결을 보장하는 기능은 아니다.

실거래 목표 달성은 당일 원주문의 체결 수량으로 확인한다. 단순 접수는 달성이 아니다. 미확정/잘못된 체결 내역은 예외 적용을 보류하며, 주문 직전에도 다시 확인한다. 현재 프로그램의 DAY 주문을 대상으로 검증했다. 전날 외부에서 제출한 GTC 주문이 오늘 체결된 경우의 체결일 집계는 지원 범위 밖이다.

과거 `daily_forced_order_enabled`는 계속 비활성 필드다. 새 옵션은 기존 설정 파일 읽기/쓰기 및 설정 화면 저장을 통해 유지되고, 기본값 초기화 시 꺼진다.

재실행용 `gui --start-paused`는 이번 실행에서만 자동 시작을 막는다. 설정은 유지되고 계좌 조회는 가능하며, 사용자가 **자동매매 실행**을 누르면 운영을 시작한다. 이 작업에서는 실주문을 실행하거나 실제 체결을 확인하지 않는다.
